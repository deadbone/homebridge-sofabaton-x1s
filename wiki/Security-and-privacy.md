# Security and privacy

## English

- No telemetry.
- No analytics.
- No SofaBaton cloud login.
- No npm post-install system mutation.
- No shell command execution.
- Local network communication only with the configured X1S hub.

The plugin stores only configuration and Homebridge accessory state needed to expose the configured activities.

## Francais

- Pas de telemetrie.
- Pas d'analytics.
- Pas de connexion cloud SofaBaton.
- Pas de modification systeme post-install npm.
- Pas d'execution de commandes shell.
- Communication reseau locale uniquement avec le hub X1S configure.

Le plugin stocke uniquement la configuration et l'etat d'accessoires Homebridge necessaires pour exposer les activites configurees.
